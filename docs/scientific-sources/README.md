# المرجعية العلمية المختارة لمُعين

**المصدر المستخدم: موسوعة القرآن الكريم QuranEnc، لترجمات معاني القرآن إلى الإنجليزية والفرنسية.** المصدر موجود بالفعل في مسار المعالجة؛ هذه الحزمة توثق اختياره ودليل وروده ضمن مرجعية التحدي، ولا تضيف تكاملًا برمجيًا جديدًا.

## دليل الاختيار

وثيقة [المرجعية والحزمة العلمية والبيانات](source_AI_challenge.pdf)، نسخة 20 / 3 / 1448، قدمها صاحب المشروع. تذكر **QuranEnc صراحة في الصفحة 9** ضمن منصات جمعية خدمة المحتوى الإسلامي باللغات، وتصف ترجمات معاني القرآن المتاحة عليها بأنها معتمدة. تتناول الصفحة 8 مراجعة محتوى الجمعية، وتميز الصفحة 11 بين منصاتها والمراجع الخارجية.

هذا يثبت ورود المصدر في الحزمة. لا يعني أن الجهة المنظمة اعتمدت تطبيق مُعين أو راجعت مخرجات ترجمته الآلية.

## ما نستخدمه فعليًا

| العنصر | الموجود في المشروع |
| --- | --- |
| الناشر | [QuranEnc](https://quranenc.com/) |
| الإنجليزية | Rowwad Translation Center، الإصدار **1.0.19** |
| الفرنسية | Rachid Maach، الإصدار **1.0.3** |
| النص العربي | نصوص الآيات المحاذاة من QuranEnc |
| التغطية | **6,236 آية** مع مرجع السورة والآية وبيانات المصدر والإصدار والحواشي |
| بيانات المصدر | [سجل القرآن الموجود في المستودع](../../base-station/benchmark-data/staging-renderings/renderings.quranenc.json) |
| الإسناد وشروط المصدر الموثقة | [إشعار QuranEnc](../../QURANENC_NOTICE.md) |
| أصل الاختيار وتجهيز النسخة | [بحث المصدر](../../base-station/benchmark-data/rendering-research.md) |
| دليل الاستخدام في التطبيق | [خادم المعالجة](../../base-station/moin_studio/server.py) يحمّل السجل ويقدمه لمسار المعالجة؛ [بوابة القرآن](../../base-station/moin_benchmark/safety.py) تستخرج النصوص المنشورة عند المطابقة |

تستخدم بوابة القرآن النصوص المنشورة عند التعرف على اقتباس مطابق وفق منطقها الحالي. لا يدعي هذا التوثيق أن الكشف يغطي كل اقتباس أو أن جميع الحالات الملتبسة حُسمت. ترجمة كلام الشيخ خارج النص القرآني تتم عبر خط الترجمة الآلية القائم، ولا تُنسب إلى QuranEnc.

لم نغير النصوص أو إصداراتها في هذه المهمة، ولم نفحص أحدث إصدار منشور على الموقع. تحفظ بيانات التحقق في [سجل الملفات والإصدارات](source-manifest.json).

## مستويات المحتوى: مرجعية موثقة، وليست تنفيذًا جديدًا

تعرف الصفحة 2 من الحزمة المستويات الآتية:

| المستوى | الضابط الوارد في الحزمة |
| --- | --- |
| أ: معلومات أصلية مستقرة | إجابة مباشرة موثقة بالمصدر |
| ب: شرح وتعريف واستدلال | من المادة المعتمدة مع إظهار المرجع وتجنب القطع فيما يحتمل الخلاف |
| ج: مسائل خلافية أو عالية الحساسية | إجابة مقيدة بالمعتمد، أو بيان الخلاف، أو إحالة للمختص |
| د: فتوى أو حالة شخصية | لا حكم مستقل؛ معلومات عامة وإحالة إلى جهة مؤهلة |

تسجيل هذه المستويات هنا لا يعني أن مُعين يملك مصنفًا لها أو نظام إحالة مكتملًا. النطاق الحالي اختيار المصدر وتوثيقه فقط.

## مراجع إضافية في الحزمة لم نربطها بالتطبيق في هذه المهمة

- الصفحة 4: [قاموس الجمهرة](https://islamic-content.com/dictionary) مرجع للمصطلحات الشرعية الحساسة، ويقدمه الدليل على الترجمة التلقائية.
- الصفحة 10: [TerminologyEnc](https://terminologyenc.com/) مرجع للمصطلحات متعددة اللغات.
- الصفحة 9: [HadeethEnc](https://hadeethenc.com/) للأحاديث وشروحها.
- الصفحة 11: [رسالة الحرمين](https://risala.prh.gov.sa/) للمحتوى الإرشادي بلغات قاصدي الحرمين.

هذه إحالات إلى ما ورد في الملف المقدم، وليست نتائج فحص حي للمواقع أو ادعاء استخدام بياناتها حاليًا. لا حاجة لتنزيلها أو بناء تكاملات معها لهذا التسليم.
