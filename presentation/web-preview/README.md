# Moin web preview

Static visual concept for screenshots. It uses the official Moin logo, colors, and Arabic font. The upload, processing state, translations, stream list, and player are illustrative; no media is uploaded or streamed.

From the repository root, run `python3 -m http.server 8000` and open `http://localhost:8000/presentation/web-preview/`.

Use the language switch to capture English and Arabic layouts. The navigation shows the upload and Haramain live screens. On the upload screen, choose a file or press **Preview processing** to display that state; press **Show example result** to return to the sample output.
